# 📦 박스권 스캐너

👉 **바로 사용하기: https://hawfinch1-box-scanner-app-xcrhdn.streamlit.app**

국내(코스피·코스닥)·미국(나스닥) 전 종목 중 **최근 일정 기간(최소 5거래일 = 1주 이상) 좁은 범위에서 횡보 중인 종목**을 찾아주는 웹앱입니다.

## 기능
- 조건: 최소 박스 기간, 박스 폭(%), 상단·하단 터치 횟수, 종가/꼬리 기준, 최소 거래대금
- 결과 표: 박스 기간, 상단·하단, 박스 안 현재 위치(하단 근처/상단 근처 필터), CSV 다운로드
- 이동평균선: 5·10·20·60·120일선 선택, 이평선 밀집(수렴) 조건, 현재가가 기준 이평선 위/아래 조건
- 가격 고정 종목 제외: 인수합병 대기처럼 거의 움직이지 않는 종목(일 등락률 표준편차 0.3% 미만) 제외
- 종목을 클릭하면 캔들 차트에 박스 구간·이동평균선·거래량을 표시

## 판별 방식
오늘을 끝으로 하는 최근 N거래일 구간에서
1. (최고가 − 최저가) / 최저가 ≤ 박스 폭 상한
2. 종가 회귀 추세선의 변화폭 ≤ 박스 높이 × 0.5 (꾸준한 상승·하락 제외)
3. 상단 20% 구간과 하단 20% 구간에 각각 최소 터치 횟수 이상 도달

을 모두 만족하는 가장 긴 N을 박스 기간으로 봅니다.

## 과거 유사 사례 수집

스캔 결과의 차트 아래에서 최대 20종목을 선택하고 **과거 사례 수집하기**를 누릅니다.
현재 보유한 약 250개 일봉을 재사용하며, 추가 시세 다운로드는 하지 않습니다.
전체 사례와 현재 선택 종목의 유사 사례를 각각 CSV로 내려받을 수 있습니다.
CSV에는 종목코드·종목명·시장, 시세 시작일·마지막일, 수집 시각, 검색 조건 JSON과 규칙 버전이 포함됩니다.
서버에 영구 누적하는 데이터베이스는 아니므로 파일을 보관하세요.
CSV는 두 가지입니다. **원본**은 값을 그대로 저장합니다(파일 안에서 종목코드 앞자리 0 보존).
**엑셀용**은 종목코드를 `="005930"` 형태로 저장해 엑셀에서 열어도 앞자리 0이 사라지지 않습니다.

### 수집 규칙

- 각 과거 날짜까지의 데이터로만 현재 검색 조건을 평가합니다.
- 첫 탐지일의 상단과 하단을 고정합니다. 이후 확정 종가가 상단보다 크거나 하단보다 작으면 그날 종료합니다.
- 경계와 같은 종가나 장중 고가·저가 이탈은 종료가 아닙니다.
- 한 종목에서 사례를 추적하는 동안 재탐지하지 않으며, 종료 다음 봉부터 새 구간을 구성합니다.
- 탐지 다음 봉을 1로 세며, 미종료 사례는 관찰 중으로 보존합니다. 그 관찰봉수는 잔여 기간이 아닙니다.
- 박스 형성에 고가·저가를 선택해도 종료는 종가로 판정합니다. 확인 가능한 장중 잠정 봉은 항상 제외합니다.
- 시세 오류가 있는 종목은 건너뛰고 화면에 따로 알립니다.

### 유사 사례 비교

- 스캐너의 박스는 "오늘 기준 가장 긴 구간"이고, 과거 사례는 "처음 탐지된 날"의 값입니다. 정의가 달라 그대로 비교하지 않습니다.
- 대신 선택 종목에도 같은 수집 규칙을 적용해, 지금 이어지는 사례(관찰 중)의 **탐지 당시** 기간·폭·위치로 비교합니다.
- 지금 이어지는 사례가 없으면(최초 탐지 경계를 이미 벗어난 경우) 비교하지 않고 그렇게 안내합니다.
- 기간·폭·위치의 허용차는 사용자가 정합니다. 예측 성능이 검증된 유사도 모델은 아닙니다.
- 분석일 이전에 탐지된 사례만 보이며, 현재 사례 자신은 뺍니다.

### 한계

현재 종목 목록에 포함된 종목만 사용하므로 과거 상장폐지 종목 등이 누락됩니다.
거래정지·시세 누락일은 원본 수집 방식상 빠지므로 관찰봉수는 실제 시장 거래일 수와 다를 수 있습니다.
그래서 거래일 달력(분석 종목 절반 이상이 거래한 날) 기준의 `탐지후달력거래일수`와 `탐지후누락일수`를 함께 기록합니다.
탐지일은 박스가 가장 좁게 잡히는 때인 경우가 많아, 고정 경계를 벗어나는 종료가 1~5봉 안에 자주 나옵니다.
약 250봉 범위에서 처음 발견한 박스이므로 수집 범위·탐지 조건에 따라 사례와 탐지 시점이 달라집니다.
과거 값의 사후 수정·주식분할 영향을 별도로 교정하지 않습니다.
중복 구간을 줄이기 위한 비중첩 수집이며 모든 가능한 박스를 열거하지 않습니다.
현재 결과는 탐색용 사례이며 유지 확률·수익률·확정 종료일을 예측하지 않습니다.
